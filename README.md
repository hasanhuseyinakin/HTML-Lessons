# HTML-Lessons
This repository is a completely free and open-source HTML programming course created by Hasan Hüseyin Akın. As a high school student i wanted to help others by sharing what we've learned.
 I  progressed slowly, starting with the simplest
 concepts and adding new lessons daily. My goal is to create a simple and
 example-rich resource that anyone who wants to learn HTML from scratch
 can understand. All the code is open source; anyone can
 run it, correct errors, or add new code. We hope it will be useful to you and wish you good luck :)
